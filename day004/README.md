## 作ったもの

### 1. 1から100までの合計

1から100までの整数を足し合わせ、合計 `5050` を計算するプログラムを作成した。

```python
total = 0

for i in range(1, 101):
    total += i

print(total)
```

**学んだこと：**

* `range(1, 101)` は1から100までの整数を生成する。
* `total += i` は `total = total + i` と同じ意味。
* ループの外で `total = 0` と初期化し、ループの中で値を累積する。

### 2. 入力を繰り返すプログラム

ユーザーが `q` を入力するまで、入力された文字列を表示するプログラムを作成した。

```python
user_input = input("Enter something (q to quit): ")

while user_input != "q":
    print("You entered:", user_input)
    user_input = input("Enter something (q to quit): ")

print("finish!")
```

**学んだこと：**

* `while` は条件が `True` の間、処理を繰り返す。
* `user_input != "q"` は、入力が `"q"` ではないことを表す。
* `input()` の戻り値を変数に保存して、ループの中で更新する必要がある。
* ループの条件が `False` になると、ループの後の処理に進む。

## 今日の学び

### `for` と `while` の違い

| 文       | 用途                 |
| ------- | ------------------ |
| `for`   | 決まった範囲や要素を繰り返し処理する |
| `while` | 条件が成立している間、処理を繰り返す |
| `break` | ループを途中で終了する        |

### 今日のポイント

**繰り返し処理では、変数の初期化・更新・終了条件を意識する。**

特に `while` では、ループ内で条件に関わる変数を更新しないと、無限ループになる可能性がある。
