## 作ったもの

誕生日を6月1日として、100日後の年齢を自動的に計算するプログラム。

例えば、現在が2026年10月7日、年齢が31歳の場合、

```text
今日: 2026-10-07
100日後: 2027-01-15
100日後の年齢: 31
```

と表示される。

## ポイント

100日後の日付が誕生日を過ぎているかを`if`文で判定し、誕生日を過ぎていれば年齢を1歳増やす。

```python
if (future_date.month, future_date.day) >= (birthday_month, birthday_day):
    future_age = age + 1
else:
    future_age = age
```
